# Simple Python Calculator

A command-line calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles invalid input
- Prevents division by zero

## Requirements
- Python 3
- Git

## How to Run
Open the terminal in the project folder and execute:

```bash
python calculator.py
```

## DevOps Learning
This project demonstrates basic Git version control,
repository initialization, commits, and pushing code
to a remote GitHub repository.
